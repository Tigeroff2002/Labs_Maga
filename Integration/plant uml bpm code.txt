!define RECTANGLE class
skinparam nodesep 10
skinparam ranksep 50

package "Клиентская часть" {
  [Frontend Client] as Frontend
}

package "Бэкенд сервисы" {
  [Logistic-API] as API
  [Logistic-Builder] as Builder
  [Logistic-Payment] as Payment
}

database "Logistic-DB" as DB {
  [Таблицы команд]
  [Outbox таблицы]
}

package "Внешние сервисы" {
  [OAuth Service] as OAuth
  [YooMoney Payment Gateway] as YooMoney
  [OpenStreetMap Service] as OSM
}

' Основные соединения
Frontend -[#blue]--> API : HTTP REST (запросы)\n**1. Пользовательские действия**
Frontend <-[#blue]-> API : WebSocket (двунаправл.)\n**2. Реальные обновления**

API -[#green]--> OAuth : HTTP REST\n**3. Аутентификация**

API -[#red]-> DB : CRUD операции\n**4. Сохранение команд**
Builder -[#red]-> DB : Чтение команд\n**5. Outbox паттерн**
Payment -[#red]-> DB : Чтение команд\n**6. Outbox паттерн**

Payment -[#orange]--> YooMoney : HTTP REST\n**7. Платежные операции**
YooMoney -[#orange]--> Payment : HTTP WebHooks\n**8. Уведомления о платежах**

Builder -[#purple]--> OSM : HTTP GET\n**9. Получение картографических данных**

Builder -[#brown]--> API : HTTP WebHooks\n**10. Результаты построения**
Payment -[#brown]--> API : HTTP WebHooks\n**11. Статусы платежей**

API -[#blue]--> Frontend : WebSocket события\n**12. Уведомления клиента**

note right of API
  **Logistic-API:**
  - Координирует процесс
  - Управляет командами
  - Рассылает события
end note

note right of Builder
  **Logistic-Builder:**
  - Строит маршруты
  - Использует OSM данные
  - Отправляет результаты
end note

note right of Payment
  **Logistic-Payment:**
  - Обрабатывает платежи
  - Интегрирует с YooMoney
  - Управляет подписками
end note

@enduml
